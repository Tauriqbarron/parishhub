7. Dark Mode

Dark mode is not a color inversion — it is a carefully tuned alternate palette that maintains the same visual hierarchy and brand identity.

Dark Mode Rules

1. Logo switches to dark variant (white outlines, amber cross stays)
2. Accent lightens from #D97706 to #FBBF24 for contrast
3. Text muted stays #94A3B8 — works on both backgrounds
4. Semantic colors (success, error, info) do not change

10. Accessibility

Target: WCAG AAA. Every release must pass this checklist.

Contrast & Color

  • Text contrast 4.5:1 minimum (normal text)
  • Large text (18px+) contrast 3:1 minimum
  • Color never sole indicator of state
  • Focus ring visible on all interactive elements

Interaction

  • 44×44px minimum touch targets
  • cursor-pointer on all clickable elements
  • Hover transitions 150–300ms
  • prefers-reduced-motion respected

Semantic HTML

  • All images have meaningful alt text
  • Form inputs have associated <label> elements
  • ARIA labels on icon-only buttons
  • Skip navigation link present
  • Semantic elements: nav, main, section, article

Pre-Delivery

  • No emojis — use SVG icons (Lucide)
  • Responsive: 375px, 768px, 1024px, 1440px
  • Loading states on form submissions
  • Lazy load heavy assets

// tailwind.config.js — ParishHub Design Tokens module.exports = { theme: { extend: { colors: { primary: { DEFAULT: '#0F172A', light: '#1E293B', muted: '#475569' }, accent: { DEFAULT: '#D97706', light: '#FBBF24', muted: '#FFFBEB' }, }, fontFamily: { sans: ['Inter', '-apple-system', 'sans-serif'], }, zIndex: { dropdown: '10', sticky: '20', overlay: '30', modal: '40', toast: '50', }, }, }, }

12. Brand Rules

The non-negotiables. Follow these or don't ship.

Do

  • Use the M1 shield logo as the primary brand mark
  • Keep light theme as the default experience
  • Use amber sparingly and purposefully
  • Maintain clear space around the logo
  • Use Inter for all text
  • Follow the spacing scale — no magic numbers

Don't

  • Don't modify the logo colors, proportions, or orientation
  • Don't use amber as body text on white backgrounds
  • Don't introduce colors outside this palette
  • Don't use arbitrary z-index values
  • Don't use emojis as icons
  • Don't skip accessibility checks
  • Don't animate the logo without approval

This document is the single source of truth for ParishHub visual design.
